# CircuitWorkshop privacy pages

Public privacy documents for the Android game **CircuitWorkshop**, package **com.florin.circuitworkshop**, published by **FlorinCor**.

- [Privacy policy](https://florincor.github.io/circuitworkshop-privacy/)
- [Data-deletion instructions](https://florincor.github.io/circuitworkshop-privacy/data-deletion.html)
- Privacy contact: [cordunianuflorin@gmail.com](mailto:cordunianuflorin@gmail.com)

Effective date: **13 October 2026**.

This repository contains only the public policy website. Game source, binaries, signing keys, local save files and private development history are not included.

## Publishing

GitHub Pages publishes the root directory of the main branch. The site is static HTML and CSS with no scripts, forms, analytics, remote fonts or third-party assets. The empty .nojekyll file disables Jekyll processing. Updates to the HTML files on main update the published pages.

Use the privacy-policy link above for the game's store listing and advertising privacy messages. The deletion page explains Android data clearing and the difference between restarting a circuit and removing all app data; it does not imply that the game has accounts or a remote deletion service.

## Policy basis

The policy reflects the game's local DataStore saves, disabled Android app backup, no account/game backend, Google AdMob banner and App Open advertising, and UMP privacy-choice entry points. The implementation reviewed uses Google Mobile Ads SDK 25.5.0 and UMP 4.0.0. Publisher contact details match the publisher's existing public game policies.

Advertising and hosting disclosures were checked against these primary sources on 13 October 2026:

- [Google Mobile Ads SDK data disclosure](https://developers.google.com/admob/android/privacy/play-data-disclosure)
- [Google UMP integration and privacy options](https://developers.google.com/admob/android/privacy)
- [Google Privacy Policy](https://policies.google.com/privacy)
- [Google advertising information](https://policies.google.com/technologies/ads)
- [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

Keep these documents current when the app's data handling, advertising integrations or publisher contact changes.
