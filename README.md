# CircuitWorkshop privacy pages

Public privacy documents for the Android game **CircuitWorkshop**, package **com.florin.circuitworkshop**, published by **FlorinCor**.

- [Privacy policy](https://florincor.github.io/circuitworkshop-privacy/)
- [Data-deletion instructions](https://florincor.github.io/circuitworkshop-privacy/data-deletion.html)
- Privacy contact: [cordunianuflorin@gmail.com](mailto:cordunianuflorin@gmail.com)

First published 13 October 2026. Last updated 25 November 2026 for CircuitWorkshop 0.1.2.

This repository contains only the public policy website. Game source, binaries, signing keys, local save files and private development history are not included.

## Publishing

GitHub Pages publishes the root directory of the main branch. The site is static HTML and CSS with no scripts, forms, analytics, remote fonts or third-party assets. The empty .nojekyll file disables Jekyll processing. Updates to the HTML files on main update the published pages.

Use the privacy-policy link above for the game's store listing and advertising privacy messages. The deletion page explains how to clear local app data on Android and when a board restart is enough to reset a circuit.

## Policy basis

The policy covers local DataStore saves, Android backup settings, AdMob banner and full-screen ads, UMP privacy choices, and the age-group choice. The implementation uses Google Mobile Ads SDK 25.5.0 and UMP 4.0.0. Publisher contact details match the publisher's public game policies.
